附录 B — 出海情报筛选方法论（50 家目标账户系统）

用途：Pearson 企业级大客户（300 万+，Versant 测评 + Mondly 培训）拓客靶心筛选与持续情报监控的完整方法论。 本文档将原先散落在 5 份文件（作战手册 / 目标清单 / 决策人 SOP / 诊断模板 / co-sell 手册）中的规则收敛为一套可执行、可复制的筛选与运作体系。 配套数据表：出海情报追踪.csv（主表，14 列 50 行） / 出海情报追踪.xlsx（可视化筛选） / 出海情报库.md（每周归档）。

§0 方法论总览（五步闭环）

① 目标池筛选 → ② 优先级分层 → ③ 每周信号监控 → ④ 决策人挖掘 → ⑤ 语言力诊断 + co-sell 桥
        (一次性)        (一次性)        (每周一自动化)     (持续补全)      (按需触发，进单前置)

核心假设：企业出海 = 语言力刚需 = Pearson 切入点。所有筛选动作都围绕「海外收入占比 / 海外销量目标 / 大规模海外用工 + 英语门槛」三个硬指标展开。

§3 每周信号监控框架（周一自动化）

3.1 监控的四类信号

信号类型示例语言力商机含义
① 出海新动作/海外营收披露建厂、并购、海外总部迁移、出口量纪录建厂/整合期英语力刚需
② 高管或 HR 负责人变动新总裁、新 CHRO、海外业务一号位调整新官上任窗口期，决策链换血
③ 出海岗大规模招聘猎聘/BOSS/校招官网国际岗招聘门槛 = 测评 + 培训切入点
④ 海外项目/招标/订单EPC 大单、海外仓、储能订单项目团队中外协作英语

3.2 执行流程（每个周一跑一次，约 30 次 WebSearch）



  1. 读 target_accounts_50.md 的 50 家名单
  2. 对每家 WebSearch：公司名 + 「出海/海外/国际化」+ 近一周关键词（建厂/招聘/出口/签约）
  3. 命中 → 记录：公司 / 信号日期 / 信号内容 / 商机含义 / 下一步动作
  4. 写入三件套：


  • 出海情报追踪.csv  信号列覆盖更新（不追加重复行，保留 14 列 50 行）
  • 出海情报追踪.xlsx  regen_xlsx.py 重新生成（P0 橙 / P1 黄 / P2 绿、首行冻结、自动筛选）
  • 出海情报库.md      顶部插入「### YYYY-MM-DD 周报」区块（TOP5 urgent + P0/P1/P2 分组）


  1. 写自动化 memory.md（执行摘要）




3.3 周报结构（归档格式）


  本周概览：主旋律一句话 + 命中家数统计（P0/P1/P2 各几家）


  TOP 5 urgent：按「语言力商机规模 × 窗口紧急性」排序的前 5 家，每条含：信号 → 商机含义 → 下一步动作


  P0 分组：全 9 家逐条更新（含「持续」标记维持主表信号列）


  P1/P2 分组：仅列本周有新增信号的家数 + 「持续」名单


  说明：数据窗口、口径、待补字段声明


3.4 工具与数据源


  WebSearch（主工具）；已连接连接器可补强：ima-mcp（知识库）、mx-ds-mcp（东方财富金融数据）、westock-mcp（腾讯自选股）、企查查/天眼查（联系人，按需）


  招聘信号反查：猎聘 / BOSS 直聘 / 公司校招官网


  财务数据：东方财富 / 新浪财经 / 巨潮（年报）


  基建/项目：中国对外承包工程商会 / 公司公告 / 央企官网




§4 决策人挖掘方法论（找到「能批 300 万的人」）


4.1 核心认知（脉脉失效后的正确打法）


  脉脉不是用来「搜名字」的，是「拿到名字后加人/发消息」的工具。


  大厂 CHRO / 国际化总裁姓名藏在公开来源里，不藏在脉脉里。


4.2 找人顺序（先挖名字，再上脉脉）




  1. 企查查/天眼查「主要人员」→ 法定代表人 + 董事 + 高管真名（免费）
  2. 年报/高管页（东方财富/新浪/cfi.cn）→ 全高管名单 + 简历 + 分管领域
  3. 新闻/HR 媒体（财富中文网/HRflag/晚点 LatePost）→ CHRO/国际化总裁这类职能大佬
  4. 猎聘 → 搜公司看人才库，HRD/副总裁简历可见，强于脉脉
  5. 探迹/励销云/销售易 → 付费按「公司+职位」出手机号（花钱但最快）
  6. co-sell 伙伴（北森/Mercer/WTW/KornFerry/Moka）→ 直接引荐 CHRO，最暖、转化最高

§5 对标报告方法论（进单钩子：免费对标扫描）


5.1 定位


用公开可验证数据对客户做一次「出海人才语言 readiness」免费体检，作为首次触达（邮件/微信/co-sell 引荐随附）的钩子。三段价值：显专业 / 全是关于他家 / 逼他问「你咋知道这么细」。


注：原「v2 深度版 / v3 专业咨询版」语言力诊断模板已淘汰，统一收敛为「对标报告」单一交付物。


5.2 核心原则（对标 bibliometric 报告）


  所有「计数」必须来自抽样 JD / 公开披露，宁少勿虚（抽样 15–30 个国际岗即可画出语言需求分布）


  评分卡每维必须写证据，否则即泛泛而谈


  数据来源逐条列 URL，让客户能反查


  对标维度必须含「同业」，否则只是自说自话


5.3 对标报告结构（8 段）


段落内容
执行摘要Headline KPI + 结论先行
方法论总体/抽样框架（n=xx）、纳入标准、局限声明
标的画像区域营收拆解表 + 全球足迹计数
语言需求图谱按语种/职能/区域三维计数（核心）
LRI 评分卡10 维 × 1–5，AHP 赋权，每维带证据 + 百分位
同业对标2–3 家同行同维度打分
风险量化把语言 gap 翻译成「钱」：情景分析（保守/基准/激进）+ ROI 视角
软 CTA免费基线扫描（2 周交付）+ co-sell 钩子


5.4 关键分析句式（穿透力）


  「高暴露—低刻度错配」：海外营收占比高但语言力无统一刻度


  「X 亿增量恰来自均值 2.2–2.4 的高摩擦市场（巴西/中东/非洲法语区）」


  「语言力不是 HR 成本项，是 X 亿出海营收的前置约束条件」
