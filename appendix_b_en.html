Appendix B — Outbound-intel screening methodology (50-account system)

Purpose: the complete, repeatable screening-and-operations system behind the Pearson enterprise key-account engine (¥3m+ deals, Versant assessment + Mondly training) — target-account bullseye screening and continuous intel monitoring. This document consolidates the rules formerly scattered across five files (playbook / target list / decision-maker SOP / diagnostic template / co-sell handbook) into one executable, replicable screening-and-operations framework. Companion data: outbound-intel.csv (master, 14 cols × 50 rows) / outbound-intel.xlsx (visual filter) / outbound-intel-log.md (weekly archive).

§0 Methodology overview (the five-step loop)

① Target-pool screening → ② Priority tiering → ③ Weekly signal monitoring → ④ Decision-maker mining → ⑤ Benchmark diagnostic + co-sell bridge
        (one-off)              (one-off)             (every-Monday automation)        (continuous build-up)          (triggered on demand, pre-deal)

Core assumption: enterprise outbound = language-capability need = Pearson entry point. Every filter runs on three hard metrics: overseas-revenue share / overseas-volume target / large-scale overseas hiring with an English bar.

3.2 Execution flow (run every Monday, ~30 WebSearches)

  1. Read the 50-list in target_accounts_50.md
  2. WebSearch each: company + "overseas / international" + last-week keywords (plant-build / hiring / export / signing)
  3. Hit → record: company / signal date / signal content / opportunity meaning / next step
  4. Write the three-piece set:
  • outbound-intel.csv — update signal column (no duplicate rows; keep 14 cols × 50 rows)
  • outbound-intel.xlsx — regen_xlsx.py regenerates (P0 orange / P1 yellow / P2 green, freeze top row, auto-filter)
  • outbound-intel-log.md — insert "### YYYY-MM-DD weekly" block at top (TOP5 urgent + P0 / P1 / P2 groups)
  1. Write automation memory.md (execution summary)

3.3 Weekly-log structure (archive format)

§4 Decision-maker mining methodology (find the person who approves ¥3m)

4.1 Core insight (the post-Maimai playbook)

Maimai isn't for "finding names" — it's for "adding / DMing once you already have the name."

Big-company CHRO / international-president names live in public sources, not inside Maimai.

4.2 Find-order (mine names first, then go to Maimai)

  1. Qichacha / Tianyancha "key personnel" → legal rep + directors + execs' real names (free)
  2. Annual-report / exec pages (Eastmoney / Sina / cfi.cn) → full exec list + bios + domains
  3. News / HR media (Fortune China / HRflag / LatePost) → CHRO / international-president types
  4. Liepin → search company talent pool; HRD / VP resumes visible, stronger than Maimai
  5. Tanji / Liaoxiao / SalesEase → paid, "company + title" → mobile number (costs but fastest)
  6. co-sell partners (Beisen / Mercer / WTW / KornFerry / Moka) → direct CHRO intros, warmest, highest conversion

§5 Benchmark-report methodology (the hook: free benchmark scan)

5.1 Positioning

A free "outbound talent language readiness" health-check built from public, verifiable data, used as the first-touch hook (email / WeChat / co-sell intro attachment). Three values: shows expertise / all about them / makes them ask "how do you know so precisely."

Note: the legacy "v2 depth / v3 consulting" language-readiness diagnostic templates are retired; the benchmark report is now the single deliverable.

5.2 Core principles (bibliometric benchmark report)

Every count must come from sampled JDs / public disclosures — fewer-but-real (sample 15–30 int'l roles to map the language-need distribution)

Every scorecard dimension must cite evidence, else it's generic talk

Every data source lists a URL so the client can reverse-check

The benchmark must include a peer dimension, else it's just self-talk

5.3 Benchmark-report structure (8 parts)

PartContent
Exec summaryHeadline KPI + conclusion-first
MethodologyPopulation / sampling framework (n=xx), inclusion criteria, limitation disclaimer
Target portraitRegional revenue breakdown table + global-footprint count
Language-need mapCounts by language / function / region (core)
LRI scorecard10 dims × 1–5, AHP-weighted, each with evidence + percentile
Peer benchmark2–3 peers scored on the same dimensions
Risk quantificationTranslate language gap into money: scenario analysis (conservative / base / aggressive) + ROI view
Soft CTAFree baseline scan (2-week delivery) + co-sell hook

5.4 Key analytical sentences (penetrating)

"High-exposure / low-calibration mismatch": high overseas-revenue share but no unified language calibration

"¥X bn increment comes precisely from high-friction markets averaging 2.2–2.4 (Brazil / Middle East / French-speaking Africa)"

"Language capability isn't an HR cost line — it's the front constraint on ¥X bn of outbound revenue"

§6 co-sell bridge methodology (turn a name into a meeting)

6.1 Core insight

Names are the bullseye (who precisely); co-sell partners are the bridge (how to enter the CHRO room). Both together are what work.
